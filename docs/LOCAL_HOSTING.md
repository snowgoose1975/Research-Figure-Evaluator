# 本机免费试用托管

固定入口：https://figure-relay.chicchair5.chatgpt.site 。点击 Check my figure，网页读取仓库专用 `service-status` 分支的公开地址公告，进入当前免费 HTTPS 试用入口。无需购买域名或 PRO。临时隧道没有可用性保证；此版本适合小规模演示，不能承诺全天候生产服务。

## 玉米如何控制

- 本机控制页：http://127.0.0.1:9041 。也可以双击 `scripts/open-service-controls.cmd`。
- 暂停接单：立即拒绝新任务，取消全部排队任务；当前任务先完成，再尝试卸载模型。不会关机，也不会关闭网页。
- 恢复接单：继续受理。暂停偏好保存在忽略的 `runs/service-control/state.json`，重启服务不会擅自取消暂停。
- 没任务时卸载模型；有任务时可能占用约6.6GB显存。仅允许1个活动任务和3个等待，滚动每小时12次、滚动24小时100次。小于1GB空闲内存时不接新任务，并在排队项开始推理前再次检查；这不是内存不会耗尽的保证。
- 不会改变睡眠、电源、路由器、防火墙或系统代理。睡眠、断网、Ollama退出时无法继续推理。

## 启动

需要现有 Node >=22.12、Ollama及 `qwen3-vl:4b-instruct-16k`，并已完成生产构建。执行：

```powershell
./scripts/start-sharing.ps1
```

脚本重用已有服务；否则启动本地Next、受限队列和系统SSH隧道，均后台隐藏。SSH使用官方nokey免账号入口，不读取用户身份密钥；服务器公钥按首次信任记录在项目私有目录，变更时仍拒绝连接。私有上传/运行审计保存在本机`runs/`，没有自动删除。

也可双击`scripts/start-sharing.cmd`启动并打开控制页。玉米已选择手动启动，不执行启动项安装脚本。

地址发现器每20秒读取隧道域名轮换事件、验证/status，只将公开地址与时间提交至本仓库专用service-status分支，不碰main、私图、任务会话ID、token或模型记录；最多每小时12次公告更新。依赖既有Git凭据管理，不读取或复制凭据。不应撤销Git登录后仍假定新地址能更新。SSH进程退出后发现器尝试重新启动；网络故障仍可能中断服务。

开机启动快捷方式是独立的系统设置改动，必须取得明确许可后才运行 `scripts/install-service-startup.ps1`。未获许可时不会创建启动项；当前会话中的后台服务不依赖聊天保持打开。

## 访客与隐私边界

只上传已经公开的PNG/JPEG，最多10MB/25MP，并确认3–5条预期信息和处理许可。访客的图片和运行记录会保存在玉米电脑上；不能用于机密或未发表研究。公网仅有/status、POST/jobs和持256位随机会话ID的结果领取，无历史列表、本机控制、Ollama、任意文件或私有run访问。会话ID仅在浏览器内存中，关闭/刷新页面或重启服务可能失去访问，终态结果30分钟后从队列内存过期；磁盘审计不自动删除。不要分享网络请求中的会话能力地址。

AI反馈不代表真人理解，重建器缺陷不等于原图缺陷。失败不会被替换成成功，也不回退到教学脚本。新服务测试不混算原固定协议8/12。

## 验证和已知限制

首次HTTPS材料图由正式本地流水线完成，报告和重建可从同一会话恢复领取；首次浏览器轮询发生ECONNRESET，原始记录私存，未重新提交图片。`T14-live-first-recovered.json`记录相同任务恢复、暂停/恢复，以及采样峰值显存6627MiB；外部观察到GPU96%，采样窗口内峰值75%。空闲时恢复约12MiB显存。最低空闲RAM289MiB发生在开发构建/测试同时运行期间，不能当作隔离基准，更不能据此保证日常应用流畅。新增低内存门槛只能减少接单风险，不能限制活动任务的全部显存或RAM使用。

Cloudflare便携隧道在当前网络下连接失败，已停止该进程，未更改系统网络。localhost.run实际发生连接抖动和同连接域名轮换；固定入口通过公告发现当前地址。地址公告短暂延迟、第三方服务不可用、电脑睡眠或当前用户尚未登录都会影响服务。
