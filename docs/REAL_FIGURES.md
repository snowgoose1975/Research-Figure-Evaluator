# 正式样例来源规则

2026-10-21 玉米补充：正式试验优先采用现成真实科研图，而非匆忙自绘。本文先更新规则，再新增数据。

- 已发表科研图优先，覆盖物理/材料/数学；原理图、结构图、分析图均可。自绘图只保留为工程正控和明确标注的脚本教程。
- 每张下载前核验正文、图号、原图注、DOI/论文链接、许可及该图的单独版权声明。优先 CC BY/CC0；CC BY-SA 保留署名/相同许可要求。不将“能在线看”“arXiv可下载”等同于可重用。
- 保存原图，不为制造误读偷偷改变科学内容。第一批只用原图跑通；要做改版对照需单独记录裁剪/清晰度改动及许可，不能把作者原图贴上“差图”标签。
- 参考检查点由主代理依据图注/正文核对，明确是我们整理的 reference checkpoints，不是论文作者亲自提供的意图，更不是科学真实性认证。用户可编辑和确认。
- A/B 只收到图片；论文正文、图注、题目和参考检查点不能流入 reader prompt。外部标注用于后置检查。
- 真实论文图仅支持 live/replay；脚本教程不能冒充它的模型结果。尚无真实结果时页面显示未测试。
- `data/published/<paper-id>/` 保存原始图与来源标注，`data/manifests/published.json` 保存可审核来源记录；`public/published/` 仅放许可允许公开再分发的原图及 attribution 文件。
- 首批三域各至少一张；少量成功不等于已证明跨域高泛化。各域分别报告恢复/不确定/流程失败。
