- 主代理（脑力）：公开文件审核、Git 推送、修复误忽略 API、定义报告导读规则，维护 `src/lib/evaluation/review.ts`、Markdown 导出及对应测试。

- 导读是从现有 run 派生的显示层，不写回 run，不启动模型，不给原图判质量或自动归因。规则发现即使检查点全 retained 也必须显示。
- 优先呈现确定性的 A/B 记录差异，其次呈现重建缺口与未保留检查点；无法确认、未执行、无覆盖信息仍明确列出。
- 每项给出观察、可核查的 A/B 记录引用和下一步复核动作。引用按各侧独立 ID 查找；没有引用时明确 unavailable，不臆造像素定位。
- 首屏显示前三项，其余可展开；完整导出包含全部复核项。
