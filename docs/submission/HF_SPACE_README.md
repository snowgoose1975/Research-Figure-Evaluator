# Figure Relay

Inspect how a local AI model read and reconstructed scientific figures.

This public edition contains **recorded real runs**, not new online inference.
No model or API installation is needed to browse. New-image analysis is not connected in this edition; the page says so explicitly.

Four inspected replays cover physics, materials and mathematics, including a failed first read. The complete fixed protocol is disclosed: **8 completed, 4 failed, 12 attempts**. This is completion, not accuracy or a generalization claim. Checkpoints were project-curated and marked by the protocol script, not independently confirmed by the paper authors.

Source and local analysis app: https://github.com/snowgoose1975/Research-Figure-Evaluator

Original research figures are reproduced under CC BY 4.0, with author attribution and paper links alongside each case and in `published/ATTRIBUTION.md`. Reconstructions are approximate model-derived diagrams and do not establish scientific correctness or human readability. Current offline rule audits are shown separately from the original saved reports.

This static edition includes no private run directory, upload endpoint, API credential, or local-model connection. Deploy the contents of the reviewed static build folder, not the local single-user server.
